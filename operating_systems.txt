An operating system manages computer hardware and provides services that allow application programs to run. The operating system manages processes, memory, storage, devices, and security. A process is a program that is currently executing. The operating system scheduler determines which process receives CPU time. Processes can move between states such as ready, running, and waiting. Context switching allows the CPU to move from one process to another. Virtual memory gives processes the appearance of having a large private memory space. Memory pages can be mapped to physical memory or stored on disk when necessary. A page fault occurs when a process accesses a page that is not currently available in physical memory. The operating system uses page tables to translate virtual addresses into physical addresses. File systems organize persistent data into files and directories. Device drivers allow the operating system to communicate with hardware devices. System calls provide an interface through which applications request services from the operating system. Applications can use system calls to open files, create processes, allocate memory, and communicate with devices. User mode restricts applications from directly performing privileged operations. Kernel mode allows the operating system to perform privileged operations. Interrupts allow hardware devices to notify the processor that an event requires attention. The operating system also provides mechanisms for processes to communicate and synchronize. Threads allow multiple execution paths to exist within a process. Locks and other synchronization mechanisms help protect shared data from concurrent access. Deadlocks can occur when processes wait indefinitely for resources held by each other. Operating systems use scheduling algorithms to decide how CPU time is distributed. Common scheduling approaches include first-come-first-served, shortest-job-first, priority scheduling, and round-robin scheduling. Operating systems also provide security mechanisms for controlling access to files, processes, memory, and hardware resources.
