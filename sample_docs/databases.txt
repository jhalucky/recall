A database is a system for storing and retrieving structured information. Relational databases organize information into tables containing rows and columns. Each row represents a record and each column represents an attribute. SQL is commonly used to query relational databases. A primary key uniquely identifies a row in a table. Foreign keys establish relationships between tables. Database indexes improve query performance by providing efficient ways to locate records. An index can reduce the amount of data that a database needs to examine during a query. Transactions allow multiple database operations to be treated as a single unit of work. Transactions commonly provide atomicity, consistency, isolation, and durability. These properties are known as ACID. Atomicity means that a transaction succeeds completely or fails completely. Isolation controls how concurrent transactions interact with each other. Durability means committed changes survive failures. Database normalization reduces unnecessary duplication of information. Joins allow queries to combine related data from multiple tables. A database query optimizer chooses an efficient strategy for executing a query. Backups protect data against accidental deletion and hardware failures. Replication can maintain copies of data on multiple database servers. Database systems can be optimized through indexes, query design, caching, and appropriate hardware.
