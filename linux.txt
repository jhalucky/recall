Linux is an operating system kernel used by many different operating systems and distributions. Linux is widely used on servers, personal computers, embedded devices, and cloud infrastructure. The Linux kernel manages hardware resources and provides essential services to applications. Processes are running programs managed by the operating system. Linux uses virtual memory to give processes an isolated address space. The scheduler decides which processes receive CPU time. Filesystems organize data stored on disks and other storage devices. Linux supports many filesystems including ext4 and XFS. The command line is an important part of Linux administration. Common commands include ls, cd, cp, mv, and grep. Permissions control which users can read, write, or execute files. Linux uses users and groups to manage access to system resources. The root user has extensive privileges over the system. Services can run in the background and provide functionality such as networking or web hosting. System logs help administrators diagnose problems. Linux networking provides tools for inspecting interfaces, routes, and connections. Shell scripts can automate repetitive administrative tasks. Package managers are used to install and update software. Linux distributions combine the kernel with utilities, libraries, package managers, and applications.
