Computer networking allows devices to communicate and exchange information. A network can connect computers within a local area or across the internet. IP addresses identify network interfaces and allow packets to be routed between networks. IPv4 uses 32-bit addresses while IPv6 uses 128-bit addresses. TCP provides reliable, ordered delivery of data between applications. TCP uses connections and retransmission to handle lost packets. UDP provides a simpler connectionless transport mechanism without guaranteeing delivery. DNS translates human-readable domain names into IP addresses. HTTP is an application protocol commonly used to transfer web resources. HTTPS adds encryption and authentication to HTTP using TLS. Routers forward packets between different networks. Switches connect devices within a local network. A port identifies a network service associated with a transport protocol. Firewalls control network traffic according to configured rules. Latency describes the time required for data to travel between endpoints. Bandwidth describes the capacity of a network connection. Packet loss occurs when packets fail to reach their destination. Network troubleshooting can involve checking interfaces, routes, DNS configuration, connectivity, and service availability. Tools such as ping, traceroute, curl, and netstat can help diagnose networking problems.
